Applied AI system + research program

Make database agents legible before making them autonomous.

SQLHarness compiles business questions into explicit semantic structure and SQL primitives, then places execution behind a governed boundary. The research question is whether that structure can improve the accuracy–cost frontier over direct LLM generation.

  • Read-only SQLite execution with time and row limits
  • Every proposal, decision, and result becomes a trace
